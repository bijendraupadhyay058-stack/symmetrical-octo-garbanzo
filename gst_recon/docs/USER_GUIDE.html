1. Install

  1. Download FinTaxPro-Setup-1.6.0.exe from the download page you were given.
  2. Double-click it. Windows may show “Windows protected your PC”, because the program is not yet signed with a code-signing certificate. Click More info, then Run anyway.
  3. Click Next through the installer. Tick Create a desktop shortcut if you want one. No administrator rights are needed.
  4. At the end, leave Start FIN TAX PRO ticked and click Finish.

Later, open it from the desktop shortcut or from the Start menu → FIN TAX PRO.

2. First start – create your login

  1. The first time, the program asks you to create the administrator: choose a user name and a password of at least 8 characters.
  2. Write the password down and keep it safe. It protects your clients’ data.
  3. Later you can add staff logins on the Security page, with their own roles (accountant, manager, read-only).

3. Try it with the sample files (5 minutes)

The installer includes demo files for a made-up client. Open them from the Start menu → FIN TAX PRO sample files.

  1. Go to Clients → New client…. Enter GSTIN 27AAPFU0939F1ZV, name Shree Ganesh Traders, and click Save.
  2. Go to Reconcile. Choose financial year 2025-26 and month 2025-04.
  3. Import purchase register… → pick tally_purchase_register_2025-04.xlsx → check the preview → Import.
  4. Import GSTR-2B… → pick gstr2b_2025-04.json → Import.
  5. Click ▶ Start Reconciliation, then Open exceptions.

EXPECTED_RESULTS.md in the same folder lists what each sample case should show.

4. Add your client

  1. Clients → New client….
  2. Enter the GSTIN. The state and PAN are filled in from it. Then enter the legal name, and choose Monthly or Quarterly (QRMP) filing.
  3. Choose the client at the top of the window (Client box) before working on it.

5. Monthly purchase reconciliation (books vs GSTR-2B)

You need two files for the month:

FileWhere to get it
Purchase register TallyPrime: Display More Reports → Account Books → Purchase Register → export to Excel. Any other Excel/CSV register also works.
No Tally? Fill in TEMPLATE_purchase_register.xlsx from the sample files folder (EXAMPLE_purchase_register.xlsx shows filled rows).
Or skip the export: click Import from Tally… while Tally is open with F1 Help → Settings → Connectivity → TallyPrime acts as: Server.
GSTR-2B GST portal: Returns Dashboard → GSTR-2B → Download (JSON or Excel).
  1. On Reconcile, choose the client, financial year and month.
  2. Import purchase register…. A preview shows every row. Rows with problems are shown in colour with the reason; nothing is changed silently. Click Import.
  3. If the program cannot recognise the columns of your file, it asks you to match them once (for example, “Bill No” = invoice number). Save the matching as a template, and next month the same file layout is read automatically.
  4. Import GSTR-2B… the same way.
  5. Click ▶ Start Reconciliation. It takes seconds, even for thousands of invoices.

6. Review the differences

  • Dashboard shows the totals: matched, differences, ITC at risk.
  • Exceptions lists every invoice that needs attention, for example “Available in Books but Missing in GSTR-2B” or “Matched with Taxable Value Difference”. Click a line to see why, set a status and remarks, and click Save review.
  • Use Confirm match or Manual match when you know two documents are the same invoice. The program remembers this for next month.
  • Suppliers shows the position supplier by supplier. Letters & papers writes a letter (Word, PDF or e-mail draft) to each supplier who has not reported invoices.
  • Export reports saves the Excel and PDF reports for the client’s file.

7. Sales register vs GSTR-1, e-invoices and e-way bills

On Sales & GSTR-1, import the sales register (or Sales from Tally…) and the GSTR-1 JSON from the portal. A ready sales register layout is in the sample files folder: TEMPLATE_sales_register.xlsx (with a filled EXAMPLE_sales_register.xlsx). Choose what to compare it with (GSTR-1, e-Invoice or e-Way bill) and click Reconcile. The same page compares GSTR-1 with the tax paid in GSTR-3B.

7a. Many clients at once (Batch)

Instead of importing client by client, put all the files in one folder and let the program do the rest.

  1. Make one folder for the batch, for example D:\GST April.
  2. Inside it, one folder per client. Its name must contain the client’s GSTIN, for example Shree Ganesh Traders 27AAPFU0939F1ZV.
  3. Inside each client folder, one folder per month, named like 2025-04.
  4. Put the month’s files there. The file name says what it is: purchase, sales, gstr2b, gstr1, gstr3b, einvoice, ewb, ims or tds – for example purchase_register.xlsx, gstr2b.json.
  5. In the program: Batch → Choose folder… → Check folder (shows what will happen, changes nothing) → ▶ Run batch.

The program imports each new file, reconciles purchases with GSTR-2B and sales with GSTR-1, e-invoices and e-way bills, and saves the Excel reports in a reports folder inside each month folder. The result list (also saved as batch_summary_….csv) shows every file and any problem with its reason. Files already imported are skipped, so you can run the same folder again after adding files.

To try it: Create example folder… makes a ready folder with the demo client. Tick Add clients that do not exist yet to add clients from the folder names. If a register’s columns are not recognised, import it once on the Reconcile page, match the columns and save a template – the batch then uses that template.

7b. Firm work dashboard

Firm work (second item in the menu) shows every client for one month on a single screen:

StageMeaning
Awaiting dataNothing imported for the month yet.
Data incompleteOne side is missing, e.g. purchase register without GSTR-2B.
Ready to reconcileBoth sides are in, but not reconciled – or new files came in after the last reconciliation.
Under reviewExceptions still open, with who they are assigned to.
Reviewed – file returnsReview done; GSTR-1 / GSTR-3B filing not recorded yet.
DoneThe month’s returns are filed.
  • The Next step column says what to do for each client, and warns when a return is overdue.
  • Deadlines lists returns not filed and notice replies, overdue or due in the next 15 days. Staff workload shows each person’s clients and open exception lines.
  • Set responsible staff… assigns a client to a staff member (also on the client form); the Staff box then shows only that person’s clients.
  • Record filing… saves the date (and ARN) a return was filed – the client moves to Done. Open client (or double-click) goes straight to that client’s work.
  • Export to Excel… saves the whole dashboard, e.g. for the weekly office meeting.

7c. Client reminders and the one-page client report

  • Reminders lists, for the month, each client who still has to send the purchase (or sales) register, or explain / correct invoices you marked Client Clarification Required or Correction Required in Books. Select a client to see a ready message; edit it if you like, then Copy message, Open in e-mail or Open WhatsApp. The program never sends anything itself – you press Send in your own e-mail or WhatsApp. Each reminder is counted, so you can see who has been reminded and when.
  • Firm work → Client report (PDF)… makes a one-page GST summary of the month for the selected client (or, with no client selected, for every client in the list): ITC as per books, GSTR-2B and GSTR-3B, ITC at risk, output tax, suppliers to follow up, returns filed or due, and what is still needed. The “Signed” name from the Reminders page is shown as “Prepared by”.

7d. Tax checks, journal and payment registers, 180-day rule, PAN view, Tally journals

Check tax types and rates

Reconcile → step 6 → Check tax types and rates… lists purchases and sales where IGST was charged instead of CGST + SGST (or the reverse) for the supplier’s / customer’s state and the place of supply, CGST + SGST of another state (e.g. a hotel elsewhere – not your ITC), and tax that is not the taxable value × a GST rate. Nothing is changed; export the list to Excel and ask the supplier for a corrected invoice.

Journal register

When expenses with GST (rent, professional fees, repairs…) are booked as journals in Tally: export the Journal Register (columnar, with GSTIN/UIN, Reference No. and the GST ledgers) and click Import journal register… in step 3. Journals with GST and a supplier GSTIN are read as bills; depreciation, provisions, TDS and ITC reversal journals are listed in the preview as not imported. Import from Tally… reads such journals automatically. Example: tally_journal_register_2025-04.xlsx.

Payment register and the 180-day rule (Rule 37)

  1. Export the Payment Register from Tally (Excel, with bill-wise details if you use them) and click Import payment register… in step 3 (or on the 180-day rule page).
  2. The ⏱ 180-day rule page lists every purchase bill: Paid in time, Not yet due, Reverse ITC (not fully paid within 180 days of the invoice date – the ITC on the unpaid part, the month in which to reverse it in GSTR-3B 4(B)(2) and an interest estimate) or Paid late – re-claim.
  3. Payments that name a bill settle that bill; the rest settle the supplier’s oldest open bills. Import purchase registers from the start of the year so that payments are matched correctly. A bill paid by cheque not in the register: select it and Mark as paid….
  4. Payments whose party is not found among the suppliers are shown in red (name spelt differently?).

PAN view

▥ PAN view shows a business registered in several states (same PAN) on one screen: each GSTIN’s ITC as per books, GSTR-2B and GSTR-3B, ITC at risk, output tax, returns overdue and notices, with totals – and the suppliers to follow up across all its registrations. Export to Excel for the client.

Tally journals

Tally journals… (on ITC review → claim register, and on the 180-day rule page) makes the month’s ITC reversal and re-claim journal vouchers as a file for TallyPrime: Gateway of Tally → Import → Vouchers. Enter the ledger names exactly as in that client’s Tally company (saved per client). Use one source per month – the claim register or the 180-day rule – so nothing is booked twice.

7e. GSTR-1 file, GSTR-3B draft and invoices by hand

Prepare GSTR-1

Sales & GSTR-1 → choose the month in From → Prepare GSTR-1 JSON…. The sales register is placed in the GSTR-1 tables (B2B, B2C large and small, credit / debit notes, exports, nil-rated, HSN summary B2B / B2C and documents issued). Documents that cannot be placed correctly – an invalid customer GSTIN, tax that fits no GST rate – are left out and listed with the reason. Save the file, open it in the GST Offline Tool (or upload it on the portal: GSTR-1 → Prepare offline → Upload), check every table, then file.

GSTR-3B draft

GSTR-3B & annual → choose the month → GSTR-3B draft (one page)…: the figures for 3.1, 3.2, 4 and 5, and Table 6.1 – how the ITC is set off (IGST credit first, as the law requires) and the cash to pay. Save it as a one-page PDF. Interest and late fee are not included.

Enter or correct invoices by hand

✎ Invoices lists a client’s purchase or sales documents. New document… adds one (e.g. a small client without Excel); select a document and Correct… to fix a wrong number, date or amount without importing the whole file again. The same checks as an import apply, and every change is kept in the audit log. If the document was already reconciled, click Start Reconciliation again for that month.

7f. Rule 42/43, e-invoice and e-way bill files, revised files, Tally ERP 9, earlier years

Rule 42/43 – common credit for exempt supplies

GSTR-3B & annual → tab Rule 42/43. Choose the month and click Show: the ITC of the month, the exempt share of turnover (from the sales register) and the credit to reverse. Enter, if any, ITC used only for non-business (T1), only for exempt supplies (T2) and only for taxable supplies (T4), tick the 5 % box if common inputs are also used for non-business purposes, and Save month – the reversal then appears in the GSTR-3B draft at 4(B)(1). Add common capital goods (e.g. a generator) with Add capital good…: 1/60 of their ITC is apportioned every month for five years. After the year, Year-end re-calculation shows what to reverse more (with interest) or to claim again in the September return.

e-Invoice and e-way bill files

Sales & GSTR-1 → month in From → e-Invoice / e-way bill JSON…. First fill the party addresses (import a party list from Tally – List of Ledgers with address, PIN and GSTIN – or add parties). The e-invoice file covers registered customers, SEZ and exports; the e-way bill file covers goods invoices above ₹50,000 (enter the vehicle or transporter for the batch). Documents missing an address, PIN or HSN are left out and listed. Upload the file on the e-invoice / e-way bill portal yourself.

Client sent a corrected file

Imports → select the old import → Replace with revised file…. You see every changed, new and removed invoice before anything is saved. Unchanged invoices keep their review work.

Tally ERP 9 and earlier years

Registers exported from the old Tally.ERP 9 (Excel 97-2003, .xls) import like TallyPrime files. For earlier years (back to 2017-18), choose the year in the Financial year box at the top – it stays when you switch clients.

7g. GST Portal section, TallyPrime GST reports, GSTR-2A / 8A, GSTR-9 and 9C files

GST Portal – download and import with one click

Open GST Portal in the left menu. Log in to GST portal opens the official portal in your browser – you sign in there yourself (FIN TAX PRO never asks for or keeps your portal password). The report buttons (GSTR-1, GSTR-2B, GSTR-2A, GSTR-3B, cash ledger, credit ledger, TDS and TCS credit, GSTR-8A / Table 8A) open the right part of the portal; point at a button to see the menu path. Save the downloads in your Downloads folder (or choose another folder). Each file is recognised – which return, which client (by GSTIN) and which month – and listed. Click Import all ready, or select files and Import selected. Returns with invoices (GSTR-1, 2A, 2B, 8A) first show the usual import preview. Files already imported are marked and are not imported twice.

The electronic cash ledger and electronic credit ledger (portal: Services → Ledgers → save as Excel) are shown at the bottom of the page with the latest balance. Downloading an overlapping period again adds only the new lines.

Without internet the page says Offline; everything else in the program works as usual, and files already downloaded can still be imported. The header shows ● Online or ● Offline.

Reconcile page

Step 4 now has GSTR-2A and GSTR-8A next to GSTR-2B. Step 3 has Tally statutory report…: in TallyPrime open Display More Reports → GST Reports, export the GSTR-1 report (imported as the sales register), the GSTR-2A / 2B reconciliation (imported as the purchase register – lines that are only on the portal are left out and listed) or the GSTR-3B report (kept as "GSTR-3B as per books" and compared with the draft in GSTR-3B draft (one page)…). Step 7 has Delete reconciliation… to remove the reconciliation shown (your imports stay).

GSTR-9 and GSTR-9C prepared elsewhere

GSTR-3B & annual → tab GSTR-9 → Import GSTR-9 (filed / offline tool)… takes the GSTR-9 JSON from the portal or the offline tool, or an Excel / CSV template with table codes (4A, 6B …). Tab GSTR-9C → Import GSTR-9C template… takes the offline tool's Excel. Both are compared with the program's working table by table; differences are shown in red. For GSTR-9C you can click Use the file's audited figures in GSTR-9C to record its Tables 5, 7 and 12 amounts.

7h. E-mail, invoices from PDF, charts and MIS, fees and staff tasks

Sending e-mails from the program

First set up your firm's mail account once: Settings → E-mail account…. Choose your provider (Gmail, Outlook, Zoho …), enter the e-mail address and an app password (for Gmail / Outlook turn on 2-step verification and create an app password – not your normal password), then Test connection. The password is kept encrypted on this computer, or not kept at all if you untick "Remember".

E-mails are never sent by themselves. These buttons put them in the Outbox (left menu):

  • Letters & papers → E-mail to suppliers… – each mismatch letter as a PDF to the supplier;
  • Reminders → Add all to Outbox – document requests to clients;
  • Firm work → E-mail client reports…, Charts & MIS → E-mail to client…, and fee invoices on Fees & tasks.

In the Outbox, click a mail to see it, type a missing address, correct the text, then select mails and Send selected. Failed mails stay there with the reason and can be sent again.

Purchase invoices from PDF

Reconcile → step 3 → Invoices from PDF… and choose the PDF invoices (as saved by the supplier's billing software). The program reads the supplier GSTIN, invoice number and date, taxable value and taxes on this computer and shows them in a check screen – yellow rows need a look (double-click the file name to open the PDF and type the right figure). Scanned PDFs (photos) cannot be read and are listed. Then the usual import preview saves them to the purchase register.

Charts & MIS

Charts & MIS shows the client's year: ITC as per books, GSTR-2B and GSTR-3B; sales and cash paid by month; and the suppliers with the most ITC at risk (point at a bar or point to see the amount). MIS pack (PDF)… and MIS pack (Excel)… make a two-page summary for the client's management.

Fees & tasks

Staff tasks: Create return tasks adds "File GSTR-1 / GSTR-3B" for every client for the month, with the due date, assigned to the client's responsible staff. They close by themselves when the filing is recorded on Firm work. Add other work with Add task…; overdue tasks are red.

Fees: fill the Firm profile… once (name, address, GSTIN if registered, bank details, invoice prefix). New fee invoice… makes a numbered invoice (GST added – CGST+SGST in your state, IGST outside; a bill of supply without GST if the firm is not registered). Record payments with Record receipt… (including TDS the client deducted). Outstanding fees by client shows what is due and for how long. A wrong invoice is cancelled, not deleted, so numbers are never reused.

9. Backups – please set this up

  1. On Security → Backups, automatic backups are on by default (every 24 hours, kept on this PC).
  2. Copy to OneDrive / Google Drive (same tab): Choose folder and turn on…, pick your OneDrive or Google Drive folder and choose a backup password. After every automatic backup an encrypted copy is saved there, so it is safe even if this computer fails. Write the password down – the copies cannot be opened without it. To restore one: Restore encrypted backup….
  3. At least once a month, click Create encrypted backup… and save the file to a pen drive or another PC. Choose a password and keep it safe: without it the backup cannot be opened.
  4. Your data is kept in %LOCALAPPDATA%\FinTaxPro. Uninstalling the program does not delete it.

9a. Updates

The program looks for a new version by itself – by default once a day; on Settings you can choose every time FIN TAX PRO starts, once a day, once a week or never. It reads only the latest version number (no client data is sent) and waits until the computer is online. When there is a new version, a blue bar appears at the top: click Download and install. The installer is downloaded, checked against the fingerprint on the download page, and started when you agree; your data is kept. You can check at any time with ⟳ Updates at the top of the window.

10. If something goes wrong

Message or problemWhat to do
“Windows protected your PC”More info → Run anyway (see step 1).
“FIN TAX PRO could not start on this computer”Send the file named in the message (%LOCALAPPDATA%\FinTaxPro\startup-error.txt) to your support contact. It describes the PC and the problem; it contains no client data.
“Column mapping needed”Match the columns once on the screen shown and save a template (step 5.3).
“Already imported”That exact file is already in. To replace it, remove the old import on the Imports page first.
Imported the wrong fileImports → select the file → Remove import…. If it was already used in a reconciliation, the program lists that reconciliation and deletes it too, after you confirm. Then import the correct file and click ▶ Start Reconciliation again.
Delete a reconciliationHistory → select the run → Delete reconciliation…. The imported files are kept. Administrator login needed.
Delete a client (e.g. the sample client)Security → Data deletion → Delete current client permanently… and type the client’s GSTIN. Cannot be undone – make an encrypted backup first for a real client.
Rows rejected in the previewThe reason is shown on each row, for example an invalid GSTIN or a missing invoice number. Correct the register and import it again.
“Tally did not answer”In Tally: F1 Help → Settings → Connectivity → TallyPrime acts as: Server, port 9000, and keep the company open.
Forgot the passwordAnother administrator can reset it on Security. If you were the only administrator, restore a backup made while you knew the password.
